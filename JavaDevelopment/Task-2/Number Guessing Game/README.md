# Number Guessing Game

## Description
The Number Guessing Game is a Java console application where the computer generates a random number between 1 and 100. The player has to guess the correct number within a limited number of attempts. The game provides hints like "Too High" and "Too Low" to help the player.

## Features
- Random number generation (1–100)
- User input using Scanner
- Too High / Too Low hints
- Maximum 7 attempts
- Play Again option
- Round Summary
- Displays correct number if the player loses

## Technologies Used
- Java
- Eclipse IDE
- Scanner Class
- Random Class

## How to Run
1. Open the project in Eclipse.
2. Run `NumberGuessingGame.java`.
3. Enter your guesses in the console.
4. Continue until you guess the correct number or use all attempts.
